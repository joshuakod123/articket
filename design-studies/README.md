# 아티켓 디자인 검토

[티켓 다섯 장](boards/tickets.jpg) · [다섯 가지 홈](boards/homes.jpg) · [서류철 만들기](boards/folders.jpg)

시안별 화면은 [매표소](boards/set-1.jpg), [전시 도록](boards/set-2.jpg), [인화실](boards/set-3.jpg), [관람 여권](boards/set-4.jpg), [하루 한 장](boards/set-5.jpg)에서 비교할 수 있습니다.
각 세트는 홈, 스크랩북, 티켓 상세, 기록 남기기, 꾸미기로 구성됩니다. 서류철 만들기 5장은 추가 비교 화면입니다.

ZIP을 풀고 index.html을 브라우저에서 여세요. 위쪽 선택기로 시안과 화면을 고릅니다. 기록 남기기에서 제목을 입력하면 티켓에 즉시 반영됩니다. 기록 저장을 누르면 꾸미기 화면에서 레이아웃과 용지 색을 바꿀 수 있습니다. 스크랩북에서 서류철 만들기를 누르면 이름과 표지를 시험할 수 있습니다. 이 파일은 디자인 검토용이며 예시 전시와 장소를 사용합니다. 서버에 저장하는 기능은 없습니다.

05 AT 로고와 앱의 한글 글꼴을 사용했습니다. 세 판화 포스터는 이 시안을 위해 새로 그렸습니다. 종이의 접힌 면, 식물 표본, 오후의 빛을 모티프로 사용했습니다.

## 디자인 참고 자료

- [Pentagram · The Public Theater](https://www.pentagram.com/work/the-public-theater) — 공연에 정체성을 부여하는 제목 활자와 판면의 대비를 살펴봤습니다. 홈의 글자 크기와 포스터 안의 제목 크기를 다르게 설계했습니다.
- [Envato · Art Gallery App UI Kit](https://elements.envato.com/art-gallery-app-ui-kit-85E5E2Z) — 작품이 바뀌어도 같은 위치에서 제목과 소장 정보를 읽는 방식을 참고했습니다.
- [Dribbble · relive](https://dribbble.com/shots/24595032-relive-Mobile-App-Design-Concept) — 사진으로 방문 순간을 찾아가는 방식을 인화실의 인화지 선택에 적용했습니다.
